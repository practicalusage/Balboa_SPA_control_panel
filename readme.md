Replacing a Balboa control panel on a CAL SPA hot tub

Using the reverse engineering of netmindz and tisiai I was able to replace a control panel (the panel on top with the buttons and display) of an old Cal Spa (California Spa) from 2005.

This code is compatible with the GL series of main boards (the main board inside the Hot Tub). Mine is a GL9800 but the GL2000 series should be compatible.

There are now two version. One includes Bluetooth communications.<pr> The BLE code is cleaner, as this is the one I'm using in production.
